# Free Resources Index

Single curated list. Every resource is free. **One primary per subject** — backups are for a specific concept that didn't land, not for re-watching the whole subject.

> **Per-topic alternatives live in `topic-lectures.md`.** This file answers "which series do
> I follow for DBMS". That one answers "three people who explain B+ tree insertion", for
> each of the 124 syllabus topics, and the planner shows them under the day's sessions.

> Playlist URLs were taken from the GO Classes official free-playlist list (verified 2026-09-13). YouTube playlists get renamed or re-ordered — if a link breaks, go to the channel's Playlists tab and search the subject name. Lecture numbering is **not** fixed in the phase plans: on the first day of each subject, map this week's topics to video numbers in your daily log.

## PYQs & Practice (the core of GATE prep)

| Resource | URL | Use it for |
|----------|-----|------------|
| GATE Overflow (GO) | https://gateoverflow.in | **Primary PYQ source.** Every GATE CS question since 1987, tagged by subject/topic/year, with discussions |
| GO — subject PYQ pages | e.g. https://gateoverflow.in/questions/operating-system?sort=gate | Subject-wise PYQs. Pattern: `gateoverflow.in/questions/<subject>?sort=gate` |
| GO — topic tags | e.g. https://gateoverflow.in/tag/pointers | Topic-wise PYQs. Pattern: `gateoverflow.in/tag/<topic>` — if a tag name in the curriculum doesn't resolve, use GO search |
| GO — year tags / papers | e.g. https://gateoverflow.in/tag/gatecse-2021-set1 · https://gateoverflow.in/exams/ | Year tags identify **sealed** questions (2022+). Exams page has original papers in test mode (Phase 6–7 mocks) |
| GO — previous papers index | https://gateoverflow.in/previous-years | Year-wise full papers list |
| GO PDFs (free) | https://github.com/GATEOverflow/GO-PDFs/releases | Download the latest GATE CSE release. Volume 1 = Engineering Maths, Discrete Maths, General Aptitude. Offline subject-wise PYQ practice |
| GateQA | https://gateqa.in | Alternative PYQ browsing interface |
| TCS iON virtual calculator | https://www.tcsion.com/OnlineAssessment/ScientificCalculator/Calculator.html | Use for every numerical from Week 1 |
| GATE 2027 official site | https://gate2027.iitm.ac.in | Syllabus PDFs, brochure, mock-test link (check the site), exam schedule |

## When to Add a Paid Resource

Free-only is the rule. The single exception worth discussing:

- **Paid full-length test series** — only if by the **Week 59 monthly review (Oct 2027)** the free pool (sealed papers + official mock + free all-India mocks) can't supply ~20 unseen full-length papers for Phases 6–7. Decide then, not before.

**Don't pre-buy** anything before you hit a real ceiling with free resources.
