## How to Write a Note

- **One concept per file.** Short: definitions, formulas, one worked example, traps.
- **Not a transcript.** If the note is longer than ~1 screen, it's a transcript — cut it.
- **Traps section is mandatory.** Every time the error log catches a mistake on this topic, add one line to the note's traps.
- **Link from the daily log** the day you write or update it.
- **Formulas also go into** the subject's sheet in `notes/formula-sheets/`.

Suggested skeleton:

```markdown
# <Topic> (<syllabus ID>)

## Core idea
## Definitions / formulas
## Worked example (one PYQ, your own solution)
## Traps
## Related: <other note files>
```
