## How to Use This Tracker

1. **During daily logs:** when you flag "Misses" → "Got stuck on set-associative cache bit split", append a row here with source = "daily log YYYY-MM-DD".
2. **During weekly reviews:** scan this tracker. If 3+ items share a subject, that subject gets next week's Fri PM concept-repair slot.
3. **During monthly reviews:** items active >4 weeks → escalate (extend the subject, or a dedicated remediation block).
4. **Before each full mock:** glance here. Know which sections you'll be slow in, and plan to take them in pass 2.
5. **End of Phase 6:** every active item is either remediated or explicitly *accepted as residual risk* — a topic you'll skip in the exam unless the question is trivial.

---

## Remediation Patterns That Work

- **Concept gap:** re-watch only that lecture segment → write a one-paragraph explainer in your own words → 5 PYQs on the topic → re-attempt the original failed question
- **Formula gap:** derive the formula once from scratch → add it to the formula sheet with one worked example → 5 numericals with the virtual calculator
- **Calculation errors:** slow down on NATs; write intermediate values; use the virtual calculator for every multi-step computation; re-check units and rounding before submitting
- **Misreads:** underline NOT / EXCEPT / "at least" / "which of the following is FALSE" on scratch paper before solving; re-read MSQ options independently
- **Time problems:** timed drills of 10 questions in the weak topic at 3 min / 1-mark and 5 min / 2-mark; practise abandoning at the time limit
- **Guessing losses:** apply the rule — MCQ only when 2 options are eliminated; MSQ / NAT always attempt if there's any working

---

## Remediation Patterns That Don't Work

- Re-watching an entire subject playlist (passive intake doesn't fix a specific gap)
- Re-reading notes without attempting questions
- "I'll come back to it later" without a target date
- Collecting another resource for the same topic

If a weak area sits for 2+ weeks with no remediation attempt, you're either avoiding it or it's the wrong topic to fix right now. Decide consciously: address it, or defer it with a reason.
