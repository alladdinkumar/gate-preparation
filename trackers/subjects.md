# Subjects Tracker

One row per official syllabus topic (IDs match `plan/syllabus.md` and the curriculum files). Updated every Sunday. General Aptitude lives in `aptitude.md`.

**Confidence scale:**
- 1 = lost, can't even start a PYQ
- 2 = vague memory, would need to look up the concept
- 3 = can solve standard PYQs with effort / occasional slips
- 4 = comfortable, first-try correct most of the time
- 5 = reflexive, can teach it and spot the trap in the options

**Columns:** Lecture = first-pass lecture done · Notes = short notes written · P1 = pass-1 PYQs attempted / correct (Phases 1–4) · P2 = pass-2 attempted / correct (Phase 5) · Acc = latest pass accuracy · Conf = confidence 1–5 · Last rev = date last revised.

**Rule:** any row with Conf ≤2 or Acc <50% after ≥8 PYQs → add to `weak-areas.md`. Any row not revisited in 21+ days → flag in `revision.md`.
